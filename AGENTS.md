# Project design guidance

Follow `docs/design-system.md` for the Botanical Playroom visual system and motion guidance.

When creating or revising animations or interactive motion, use https://motion-reference.takayustudio.jp/ as the design reference. Consult relevant examples and adapt them to the project; preserve keyboard accessibility and respect `prefers-reduced-motion`.

Apply the relevant repository skills in `.agents/skills`, including `svelte-rules` and `compact-headers`, when editing Svelte UI.
